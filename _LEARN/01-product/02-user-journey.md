# 用户旅程 (User Journey)

## 概述

本文档从用户视角描述使用 pi-coding-agent 的完整旅程，包括首次使用、日常使用、高级功能和团队协作场景。

---

## 首次使用旅程

### 1. 安装与配置

**步骤 1：安装**
```bash
# 使用 npm 安装
npm install -g @mariozechner/pi-coding-agent

# 或从源码运行
git clone https://github.com/mariozechner/pi-mono.git
cd pi-mono
npm install
npm run build
npm run start
```

**步骤 2：初始配置**
```bash
pi
# 首次运行会启动配置向导
```

**配置向导流程**：
1. **选择 Provider**
   ```
   ? 选择 LLM Provider:
   > OpenAI
     Anthropic
     Ollama (本地)
     Google
     其他...
   ```

2. **配置 API Key**
   ```
   ? 输入 API Key: sk-...
   ```

3. **选择默认模型**
   ```
   ? 选择默认模型:
   > gpt-4o
     gpt-4o-mini
     claude-3.5-sonnet
     ...
   ```

4. **确认配置**
   ```
   配置已保存到 ~/.pi/config.json
   ```

**生成的配置文件** (`~/.pi/config.json`):
```json
{
  "provider": "openai",
  "apiKey": "sk-...",
  "model": "gpt-4o",
  "theme": "default",
  "maxTokens": 8000
}
```

### 2. 第一次对话

```bash
pi
# 启动交互式会话
```

**UI 首次加载体验**：
```
┌─────────────────────────────────────────────────────────────┐
│  pi-coding-agent v0.70.2                       [OpenAI GPT-4o] │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  欢迎使用 pi-coding-agent！                                 │
│                                                             │
│  ? 输入您的消息或按 ? 查看帮助                              │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**第一次交互**：
```
You: 帮我创建一个 TypeScript 函数，计算数组的平均值

Agent: 当然！以下是实现：

```typescript
function calculateAverage(numbers: number[]): number {
  if (numbers.length === 0) return 0
  const sum = numbers.reduce((acc, num) => acc + num, 0)
  return sum / numbers.length
}
```

这个函数：
1. 处理空数组情况
2. 使用 reduce 计算总和
3. 返回平均值

是否需要我创建测试文件？
```

**关键体验点**：
- ✅ 流式响应，实时看到生成过程
- ✅ 代码块语法高亮
- ✅ 自动提供后续操作选项

## 高级功能旅程

### 场景 4：会话分支探索

**用户目标**：探索多种实现方案

**当前会话**：
```
You: 我需要实现一个搜索功能

Agent: 有几种方案：
1. 简单的线性搜索
2. 使用索引优化
3. 使用全文搜索引擎

想了解哪种？
```

**创建分支 A（线性搜索）**：
```
You: 先看方案 1

Agent: [实现线性搜索]

性能：O(n)
适用场景：小数据集
```

**分支探索**：
```
[按 Ctrl+B 创建分支]

├─ Main (原始对话)
├─ Branch A (线性搜索)
│  └─ A1 (代码实现)
└─ Branch B (索引搜索) [新分支]
```

**在新分支中**：
```
You: 现在看方案 2

Agent: [实现索引搜索]

性能：O(log n)
适用场景：大数据集，频繁查询
```

**对比分支**：
```
[使用 tree 命令查看会话树]

Branch A: 简单但慢
Branch B: 复杂但快

You: 对比两种方案

Agent: 方案对比：
| 维度 | 线性搜索 | 索引搜索 |
|------|---------|---------|
| 实现难度 | 简单 | 复杂 |
| 查询性能 | O(n) | O(log n) |
| 内存使用 | 低 | 高 |
| 维护成本 | 低 | 高 |

建议：
- 数据 < 1000 条：线性搜索
- 数据 > 1000 条：索引搜索
```

## 痛点与解决方案

### 痛点 1：上下文丢失

**问题**：长对话后，AI 忘记早期内容

**pi 的解决方案**：
```
[自动检测上下文大小]

上下文即将超过限制（7500/8000 tokens）

触发压缩：
✓ 保留最近 20 条消息
✓ 压缩早期对话为摘要
✓ 保留所有文件操作
✓ 保持决策历史

压缩摘要：
[显示摘要内容]

你可以继续对话，所有上下文已保留！
```

### 痛点 2：工具调用错误

**问题**：AI 执行错误的文件操作

**pi 的解决方案**：
```
[尝试写入文件]

⚠️ 警告：文件已存在且有很多改动

操作：Write
路径：/src/main.ts
风险：高

建议：
1. 使用 Edit 代替 Write
2. 先创建备份
3. 查看差异

如何处理？
a) 继续写入
b) 使用 Edit
c) 取消操作
```

### 痛点 3：重复性任务

**问题**：频繁执行相似操作

**pi 的解决方案**：
```
我注意到你经常：
1. 创建组件文件
2. 添加单元测试
3. 更新导出

我可以创建一个 Skill 来自动化这个流程。

创建 Skill: create-component

[生成 SKILL.md]

以后只需输入：
/create-component Button

就会自动完成所有步骤！
```

## 总结

pi-coding-agent 的用户旅程体现了：

1. **渐进式学习** - 从简单到复杂，逐步掌握
2. **上下文感知** - AI 理解用户意图和历史
3. **安全优先** - 危险操作需要确认
4. **可扩展性** - 从用户到专家都有成长空间
5. **团队友好** - 支持协作和知识共享

这使得 pi 成为长期编程伙伴，而非简单的工具。
